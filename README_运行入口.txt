AgentGuard executable package

Windows:
1. Double-click start_agentguard_windows.cmd, or run:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\run_demo.ps1
2. Open http://127.0.0.1:8080 in a browser.
3. Use the sample logs in data\upload_logs for upload testing.

macOS:
1. Run ./setup_env.sh on first use.
2. Run ./run_demo.sh.
3. Open http://127.0.0.1:8080 in a browser.

This package contains the trained checkpoint, demo data, local Web page,
configuration files, and runtime scripts required for the offline demo.
