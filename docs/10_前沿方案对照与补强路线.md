# 前沿方案对照与补强路线

本文档回答两个评审关心的问题：AgentGuard 与前沿论文和成熟开源工程有什么关系，以及下一步如何把自建工程基准推进到真实验证。

## 1. 一句话定位

AgentGuard 不是通用大模型，也不是杀毒软件。它做的是“AI Agent 行为审计”：把 Agent 的输入、规划、工具调用、权限变化，与主机进程、文件、网络、注册表事件放到同一条时间线上，判断这一串动作是否像一次异常行为链，并把告警证据留给人复核。

通俗说，传统日志规则像看单张照片，AgentGuard 想看一段录像。一次“读文件”可能正常，一次“连网络”也可能正常；但“不可信网页内容进入 Agent 后，Agent 提权、读凭据、外连、上传”连在一起，就需要报警。

## 2. 与前沿论文的关系

| 方向 | 代表工作 | 可借鉴点 | 当前项目差距 |
|---|---|---|---|
| 日志序列异常检测 | DeepLog、LogBERT、Anomaly Transformer、TranAD | 用序列模型学习正常行为语法，使用下一事件预测或注意力刻画异常 | 当前数据规模小，尚未在公共日志和真实 Agent 轨迹上做跨环境验证 |
| Agent 安全评测 | AgentDojo、InjecAgent、ToolEmu、Agent Security Bench、AgentHarm | 把提示注入、工具滥用、越权代理变成可复现测试任务 | 当前只把这些威胁转成自建行为模板，尚未直接运行这些 benchmark |
| AI 风险治理 | NIST AI RMF、OWASP Top 10 for LLM Applications、MITRE ATLAS | 说明可信、可解释、可追责和 Agent 特有风险 | 当前只做检测与解释原型，未实现完整治理流程 |
| 主机安全知识库 | MITRE ATT&CK、Sigma、Wazuh/Falco 规则 | 把告警映射到凭据访问、持久化、横向移动、外传等战术 | 当前映射较粗，尚未输出 ATT&CK technique ID 级别证据 |

## 3. 与成熟 GitHub 工程的关系

| 工程 | 成熟能力 | AgentGuard 应采用的方式 |
|---|---|---|
| Langfuse / Phoenix / OpenLLMetry / AgentOps | LLM 调用、工具调用、trace/span、评测与观测 | 作为 Agent 侧事件采集入口，把 span 映射为 `source=agent` |
| osquery | 用 SQL 查询主机进程、网络连接、文件和系统状态 | 作为主机侧进程/网络/文件事件来源 |
| Wazuh | 开源 XDR/SIEM，提供主机告警、规则和合规信息 | 作为规则告警来源，映射到 `event_type=alert` 或解释字段 |
| Falco | 运行时 syscall 和容器安全检测规则 | 作为高危主机动作的实时规则来源 |
| Drain3 / LogPai logparser | 在线日志模板解析 | 把非结构化文本日志先变成模板事件，再进入统一序列 |
| Loglizer | PCA、Isolation Forest、One-Class SVM、DeepLog 等日志异常基线 | 作为模型对照，不让 Transformer 缺少强基线 |
| Open Policy Agent | 通用策略引擎 | 用于管理“哪些工具/资源/上下文允许执行”，与检测分数并列展示 |

## 4. 最优先补强项

1. 真实接入小样本：从 Langfuse/Phoenix trace 导出 200 到 1000 条脱敏 Agent 工具调用，跑通 `convert_csv.py` 或 JSONL 输入。
2. 主机遥测小样本：用 osquery 或 Wazuh 导出进程启动、网络连接、文件访问，映射到同一个 `entity_id`。
3. 基线扩展：至少加入 Isolation Forest、One-Class SVM、Loglizer DeepLog 或 LSTM，对比 Transformer 单模型。
4. 场景级留出：对每个攻击族都做 leave-one-scenario-out，而不是只留出横向移动。
5. 解释验证：对 top evidence 做删除实验，观察删除关键事件后分数是否下降，避免只展示注意力热力图。
6. 阈值治理：按角色或业务类型分别校准阈值，报告 Precision、Recall、FPR 和人工复核成本。

## 5. 答辩时的诚实表述

可以说：

“我们没有声称自建数据代表生产环境。当前结果证明的是完整链路可运行、可复现、可解释，并且模型分数和透明规则互补。下一步最重要的是接入真实授权轨迹和公共安全数据，用更多基线和留一场景验证泛化。”

不要说：

“模型已经能识别未知攻击”“97% 是 Transformer 的准确率”“可以直接部署到生产自动阻断”。

## 6. 可直接扩展的实验入口

- Agent 侧：把 trace/span 导出为 `timestamp, entity_id, source, event_type, action, object_type, object_name, result`。
- 主机侧：把 osquery/Wazuh/Falco 事件映射到同样字段。
- 文本日志：先用 Drain3 做模板解析，再把模板 ID 或模板动作映射为 `event_type/action/object_type`。
- 评测侧：继续使用 `scripts/train.py`、`scripts/evaluate.py`、`scripts/analyze_stream.py`，并把真实结果与 `data/demo` 分表展示。
