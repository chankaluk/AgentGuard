# AgentGuard 模型权重与依赖说明

## 1. 权重来源

`artifacts/agentguard.pt` 由本项目 `scripts/train.py` 本地训练生成，训练输入是 `scripts/generate_demo_data.py` 以固定随机种子 2026 生成的 `data/demo/train.jsonl` 与 `validation.jsonl`。本项目未使用第三方预训练权重，也没有下载或混入组委会数据、真实用户日志或外部私有数据。

当前权重的 SHA-256 为：

```text
D131C219FB00041EA5F96DCC38967346A6EFBDFC4BE4F7BC83D5E76659A8A684
```

提交或重新训练后，应执行 `Get-FileHash .\artifacts\agentguard.pt -Algorithm SHA256` 复核并更新本页。重新训练会产生新的权重文件；即使固定随机种子，不同 PyTorch、CPU 指令集或底层库也可能导致文件哈希变化。

## 2. 模型配置与加载安全

- 网络：2 层、4 头、隐藏维度 64 的轻量 Transformer；
- 窗口：长度 24，步长 8，最少事件数 6；
- 目标：异常分类与下一事件预测的多任务训练；
- 告警：`max(Transformer 分数, 透明顺序规则分数)`；
- 权重文件大小约 0.303 MB，模型参数 67,522 个。

checkpoint 使用项目内部版本结构保存。加载时采用 `weights_only=True`，并校验顶层字段、类型和张量内容；不要加载来源不明的 `.pt`、`.pth` 或 pickle 文件。

## 3. 精确依赖

`requirements.txt` 固定了本次完整验证使用的版本：

| 包 | 版本 |
|---|---:|
| numpy | 2.5.1 |
| torch | 2.13.0 |
| python-docx | 1.2.0 |
| python-pptx | 1.0.2 |
| matplotlib | 3.11.1 |
| psutil | 7.2.2 |
| requests | 2.34.2 |

推荐 Python 3.11 或 3.12。Windows 新电脑执行：

```powershell
cd "AgentGuard"
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_env.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_all.ps1
```

`setup_env.ps1` 会创建项目本地 `.venv` 并安装精确依赖；`run_all.ps1` 本身不会安装或升级依赖。

macOS（Intel 或 Apple Silicon）执行：

```bash
cd "AgentGuard"
./setup_env.sh
./run_all.sh
```

`setup_env.sh` 和 `run_all.sh` 与 PowerShell 版本遵循相同的依赖固定和失败即停止规则。

## 4. 结果边界

当前指标来自 400 条自建工程测试序列，目的是验证软件闭环，不代表真实生产效果。97% 检出率是 Transformer 与透明顺序规则联合后的混合系统结果；Transformer 单模型检出率为 65%。真实部署必须使用授权且脱敏的轨迹，重新进行按实体、时间和场景隔离的训练、阈值校准与误报成本评估。
