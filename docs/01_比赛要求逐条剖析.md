# 自主命题赛道要求剖析与作品定位

## 1. 已确认事实

本项目参加自主命题赛道，题目由参赛队自行提出，名称为“基于行为序列建模的 AI Agent 异常检测系统”。组委会不提供本题专用数据集、字段字典或统一复测环境。因此，压缩包内原有的定向命题题目、一个月主机日志、固定误报率上限和分项权重均不能作为本作品的官方要求引用。

`00_比赛原始材料` 中原有定向赛材料只用于保留项目来历，不是本项目的需求依据。提交前应由队员从竞赛官网下载并核对当届自主命题赛道指南和模板。

## 2. 自主命题作品应形成的证据闭环

### 2.1 问题成立

需要说明 AI Agent 已能调用文件、网络、代码、数据库和其他 Agent，单个动作可能合法，但多个动作按特定顺序组合后会产生提示注入、凭据访问、权限滥用、持久化、横向移动或数据外传风险。作品聚焦“行为链异常”，不是泛化成所有 AI 安全问题。

### 2.2 方法必要

Transformer 用于学习跨事件上下文和顺序关系；下一事件预测用于补充对行为语法的学习。透明顺序规则负责覆盖已知高风险链，模型负责提供连续风险评分和对未显式编码组合的泛化能力。报告必须分别展示模型、规则与混合系统，不把规则收益算成模型成绩。

### 2.3 工程可运行

项目应支持离线安装、数据生成、训练、评测、告警导出、本地 Web 演示和干净打包。每个阶段检查退出码；测试覆盖输入边界、离线/流式窗口一致性、安全 checkpoint、指标算法和无图形界面运行。

### 2.4 结果可复核

所有数字来自自建增强工程基准，并由 JSON 指标、数据元信息、SHA-256、告警原文和复现命令支撑。工程基准只能证明当前场景下的实现效果，不代表生产效果。真实数据验证应在授权环境中由参赛队另行采集，并单独呈现。

### 2.5 创新可证实

本项目的可验证创新包括：Agent 与主机双域统一序列；分类与下一事件预测的多任务建模；模型与顺序规则的显式分层融合；注意力、惊异度、规则命中和原始日志组成的证据链；困难正常样本和留出场景用于检查捷径学习。

## 3. 当前结果与正确口径

当前 400 个测试序列上的实际混合告警结果为：检出率 97.00%、误报率 15.33%、F1 0.798、ROC-AUC 0.971。Transformer 单模型检出率为 65.00%，透明顺序规则为 84.00%。这些结果必须成组出现，并附“自建可复现增强工程基准”说明。

横向移动场景从训练和验证的异常模板中留出，Transformer 单模型在该场景未检出，规则补足了该缺口。这一结果既体现混合系统的工程价值，也暴露当前模型未知场景泛化仍需改进。

## 4. 易失分与资格风险

1. 把自主命题作品写成定向命题，或引用不属于本赛道的固定评分权重。
2. 把自建合成数据说成组委会数据、真实企业数据或正式复测成绩。
3. 只展示混合高分，不披露单模型和规则基线。
4. 只给方案和截图，没有可运行代码、原始指标和复现命令。
5. 用测试集调阈值，或让标签、场景、风险提示进入模型输入。
6. 把注意力称为因果解释，或隐藏误报、漏报和场景失败。
7. 初赛匿名文件出现学校、院系、教师、队员等身份信息。
8. 队员不了解 AI 辅助生成的代码和材料，无法完成现场源码问答。

## 5. 推荐答辩结构

10 分钟建议安排为：1 分钟问题与威胁模型，2 分钟数据和防泄漏设计，2 分钟模型、规则与融合，2 分钟分层实验结果，2 分钟现场演示，1 分钟创新、限制和落地计划。先说结论和证据，再解释技术；对自建数据边界保持主动、明确和一致。
